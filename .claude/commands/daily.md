Add a daily puzzle to Strokes by following the runbook in `docs/daily-celebration-prompt.md`
exactly, step by step: get ready, choose the puzzle (and the desktop game's 5-letter one), concept,
build, check and hand in.

The date: $ARGUMENTS. If no date was given, use the day after the latest file in
`src/daily/days/`.
